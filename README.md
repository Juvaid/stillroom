# Stillroom

Press one frame of HTML, CSS, and JavaScript — or a closed Remotion still — into a layered Photoshop file.

Type stays editable when the face is one Photoshop ships. Groups, masks, and live shadows are kept. Transforms, filters, and gradient text are baked into pixels and named in the fidelity list.

```bash
npm install
npm run dev
```

Open the source column and copy **Agent brief — Statics only** when an agent is building a still for this press, not a motion comp.
